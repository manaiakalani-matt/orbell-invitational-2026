How these numbers work

All figures come from the n01 scoring records for tournament t_ldpt_2502: every visit of every leg. The 3-dart average is n01's own: points scored divided by darts thrown, times three. Pool play used a bull check-in rule (first three check-in darts at the bull, then any double), so a run of 0 scores at the start of a leg is a player trying to check in. n01 stores one score per visit, so it can't tell which dart hit the double or the bull. "After check-in" averages and check-in visits are worked out from that run of zeros. Leg times come from n01's start and finish timestamps and include walking and scoring time.
